Conventions

Learn the contract once, use it everywhere.

RuleWhy
node tools/<name>.js --helpEvery tool prints its own usage and exits 0. Nothing to memorise.
--json on every toolPipe into jq, a script, or another tool. No scraping your own output.
Exit codes: 0 clean, 1 findings, 2 gateDrop any tool straight into CI. Findings fail the build, clean passes.
Zero runtime dependenciesNo lockfile churn, no supply-chain surface, no npm audit noise.
Read-only by defaultTools that write take an explicit --out. Nothing mutates in place.
Conservative defaultsRate limits and concurrency start low. Raise them yourself when you own the target.

Why zero dependencies

The most consequential design decision in the project.

The whole thing is auditable

41,555 lines with no transitive tree behind it. You can read what runs, and so can anyone reviewing it.

It still works in five years

No lockfile to rot, no major version to chase. Node 18+ builtins change far more slowly than the ecosystem around them.

Nothing to trust

A 200-line tool that pulls 40 packages is not a tool, it is a liability. The parsers here — ZIP, XLSX, SQLite, EXIF, TAR — are written by hand because the format is the interesting part.

It runs anywhere Node runs

A locked-down CI runner, a fresh container, an air-gapped box. Clone and go, no install step to fail.

How it's tested

Three layers, because each one misses what the previous catches.

LayerCatchesHow
smoke.js --deep A tool that will not load, or references a helper it never imported Runs every tool with --help and with no arguments, then lints syntax and import reachability across all 234 files
podcheck.js A tool that crashes at the end of its real code path 112 real invocations with generated fixtures, failing on any stack trace
assertcheck.js A tool that runs cleanly and returns the wrong answer 94 cases asserting exit codes, exact output fragments, regexes and line counts

That third layer exists because the first two missed real bugs: a file-type detector that called every short text file binary, and a JSON linter that flagged every URL as a comment.
